### 4.2 API Specification API规范

#### POST /api/enhance
**Request:**
```json
{
  "text": "string (10-50000 chars)",
  "style": "academic|business|creative|casual|concise",
  "email": "string (optional)"
}
```

**Response:**
```json
{
  "success": true,
  "result": "humanized text",
  "is_pro": false,
  "chars_used": 1500,
  "chars_remaining": 3500
}
```

**Error Codes:**
- `400`: Invalid input
- `402`: Payment required (Pro feature)
- `429`: Quota exceeded
- `500`: Server error

#### POST /api/activate-pro
**Request:**
```json
{
  "email": "user@example.com",
  "subscription_id": "I-SUBSCRIPTION123"
}
```

**Response:**
```json
{
  "success": true,
  "message": "Pro activated"
}
```

#### GET /api/check-pro
**Query:** `?email=user@example.com`

**Response:**
```json
{
  "is_pro": true
}
```

#### GET /api/config
**Response:**
```json
{
  "paypal_client_id": "AaBbCc...",
  "paypal_plan_id": "P-123..."
}
```

### 4.3 Database Schema 数据库模式

```sql
-- Users table
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    is_pro BOOLEAN DEFAULT FALSE,
    subscription_id VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Daily usage tracking
CREATE TABLE usage_stats (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255),
    chars_used INTEGER DEFAULT 0,
    usage_date DATE DEFAULT CURRENT_DATE,
    UNIQUE(email, usage_date)
);

-- Click analytics
CREATE TABLE click_stats (
    id SERIAL PRIMARY KEY,
    button_type VARCHAR(50) NOT NULL,
    click_date DATE DEFAULT CURRENT_DATE,
    count INTEGER DEFAULT 1,
    UNIQUE(button_type, click_date)
);
```
